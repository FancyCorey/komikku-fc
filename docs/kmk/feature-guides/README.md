# Komikku FC feature guides

Choose the tool you want to use. Each guide explains where to find it, what its settings change, and what to do when something goes wrong.

New to the fork? Start with [how the features work together](overview.md) or the [main user guide](../user-guide.md).

## Discovery and recommendations

- [Recommendations](recommendations.md): find manga in For You and Top Picks, adjust filters, get suggestions for a manga group, and share recommendation lists.
- [Recommendation settings](recommendation-settings.md): change your taste, filters, source choices, data use, and linked-version options.
- [Source evaluation](source-evaluation.md): check sources, understand results, continue interrupted work, and set up automatic checks.
- [Finding and prioritizing sources](sources.md): choose suggested extensions to install and decide which sources For You searches first.

## Manga preferences and cross-source tools

- [Rating manga and managing linked versions](ratings.md): save or clear a rating, rate confirmed versions together, manage groups, and undo supported changes.
- [Comparing versions](versions.md): find the same manga on another source, compare chapters and page quality, and choose which version to keep.

## Reader and local tools

- [Local tracking](local-tracking.md): edit chapter progress, share it between linked versions, and control updates from external trackers.
- [Reading and chapter navigation](reading.md): adjust the reader, use timers and schedules, switch sources, and jump to your last-read position.
- [Searching downloaded pages with OCR](ocr.md): recognize and search page text, open matching pages, and clear saved text.
- [Backup and restore](backups.md): choose what to save, check restore results, and understand what is not included.

## Source, extension, and safety boundaries

- [Troubleshooting](troubleshooting.md): what to check when a source fails, a task stops, or only some results load.
- [Managing extensions](extensions.md): install, trust, remove, or export an extension, and check the result.
- [Sharing screenshots and files](sharing.md): what name hiding covers, what exports contain, and how to handle incomplete files.
- [Links, Undo, and file safety](safety.md): open links carefully, undo supported actions, and remove identified incomplete files.
- [How features work together](overview.md): how ratings, progress, backups, and network activity fit together.
